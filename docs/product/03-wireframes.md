# 03 - Wireframes

## Visao Geral

O PetMatch possui 16 telas principais no fluxo do MVP.

---

## Fluxo de Navegacao

```
Splash Screen -> Welcome (Onboarding) -> Login/Cadastro -> Cadastro Pet (3x) -> Permissoes -> Home/Feed
                                                                                                    |
                                                                                              +-----+-----+
                                                                                              |     |     |
                                                                                        Perfil Pet  Matches  Meu Perfil
                                                                                              |     |     |
                                                                                              |  Chat Room  |
                                                                                              |     |     |
                                                                                              +-----+-----+
```
